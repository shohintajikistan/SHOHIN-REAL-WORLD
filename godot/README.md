# SHOHIN REAL WORLD — Godot 4 migration

This folder is the new Godot 4 project. The existing Three.js prototype at the repository root is intentionally preserved while the Godot foundation is tested.

- Engine: Godot 4.4.1
- Renderer: Compatibility (OpenGL), chosen as a practical starting point for Android support.
- World target: 4,000 × 4,000 metres.
- First milestone: procedural island terrain, ocean, mixed forest zones and a web preview build.
- Android APK export will be configured after the first automated project validation.

The first scene is a visual foundation, not a finished survival game. Terrain and tree geometry are procedural placeholders; realistic scanned assets, character controls, collision, gameplay systems and optimization are subsequent milestones.
