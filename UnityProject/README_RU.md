# SHOHIN SURVIVAL — Unity 6 + URP

Отдельная Unity-ветка проекта. Текущая веб-версия в `main` не изменяется.

## Что уже заложено
- Unity 6 project skeleton и зависимости URP 17, Input System и Cinemachine.
- Генератор двух крупных островов с разными seed, высотой и размером.
- Базовый third-person controller с точками подключения экранного управления.
- Игровые часы: 40 реальных минут = 1 игровые сутки, счётчик дней и сезоны.
- Основы голода, жажды, здоровья и выносливости.
- Океан с процедурным движением волн на лёгкой сетке.
- Кинематографическая основа сцены: тёплый направленный солнечный свет, мягкие тени, атмосферный туман, HDR и ACES post-processing.
- Editor setup-команда для создания тестовой сцены, двух островов, океана, тестового персонажа и cinematic volume.

## Как создать сцену
1. Открой папку `UnityProject` в Unity Hub с Unity 6.0 LTS.
2. Дождись установки пакетов из Packages/manifest.json.
3. В Unity выбери меню **SHOHIN → Create Cinematic Survival Prototype**.
4. Открой `Assets/Scenes/SHOHIN_Survival_Prototype.unity` и нажми Play.

## Важно
Это начальный Unity-прототип, не готовая игра и не APK. Сцена всё ещё использует капсулу вместо финального humanoid-персонажа и процедурный базовый рельеф. Океанская волна сейчас — базовая геометрическая анимация, а не финальный реалистичный водный шейдер. Для следующего художественного этапа нужны качественная модель человека с анимациями, деревья и кустарники, детализированные материалы островов, затонувший корабль и мобильный HUD.

URP package включён в manifest. После первого открытия проверь Project Settings → Graphics и Quality: активный Render Pipeline должен быть Universal Render Pipeline Asset. При необходимости создай URP Asset через Create → Rendering → URP Asset (with Universal Renderer) и назначь его в Graphics и Quality.

На телефоне Unity Editor не запускается как обычное Android-приложение. Репозиторий хранит исходники; сборка APK требует Unity Editor на ПК или настроенного Unity Build Automation/CI с лицензированным Unity Editor. Код этой ветки пока не был скомпилирован в Unity Editor, поэтому перед сборкой нужна проверка импорта и Console.
